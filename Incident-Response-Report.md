## 1. Executive Summary
On September 4, 2026, a multi-stage cloud account takeover (ATO) was detected against user `david.okafor@company.com`. The attacker utilized MFA fatigue to steal a session token, bypassed secondary authentication, and established a malicious email forwarding rule to exfiltrate corporate communications. 

## 2. Investigation & Timeline
As the Tier 1 Analyst on duty, I triaged three raw JSON logs from Microsoft Entra ID and Exchange Online:

*   **03:11 UTC (Initial Access):** Attacker logged in from Sao Paulo, Brazil (IP: `45.227.253.88`) using an Android device. MFA was marked as "Approved" — highly suspected to be MFA Push Fatigue.
*   **03:19 UTC (Token Hijack):** The same IP logged in again, but this time from a Windows/Edge device with **MFA = None**. 
    *   *Analyst Note:* This indicates the attacker reused the session token generated from the first login. Because the token was already trusted, Microsoft did not prompt for MFA again.
*   **03:22 UTC (Persistence & Exfil):** The attacker executed a `Set-Mailbox` operation in the Audit Logs. They created a stealth forwarding rule (`DeliverToMailboxAndForward: true`) sending copies of all incoming emails to `ceo-finance@protonmail.com`. 

## 3. Indicators of Compromise (IOCs)
*   **Malicious IP:** `45.227.253.88`
*   **Attacker Email:** `ceo-finance@protonmail.com`
*   **Compromised Account:** `david.okafor@company.com`

## 4. Business Impact
The attacker had silent access to the victim's inbox for an unknown duration, creating a high risk of Business Email Compromise (BEC), credential theft, and data exfiltration.

## 5. Remediation & Response Actions Taken
1.  **Containment:** Revoked all active sessions for `david.okafor` to instantly kill the stolen session token.
2.  **Eradication:** Deleted the malicious inbox forwarding rule and purged forwarded items from the server.
3.  **Recovery:** Forced a password reset and applied Number-Matching MFA to prevent future push-bombing.
4.  **Blocking:** Added `45.227.253.88` and `ceo-finance@protonmail.com` to the tenant block list.
5.  **Hunting:** Initiated a scan across the organization for other mailboxes with external forwarding rules.
